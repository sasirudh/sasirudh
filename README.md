## 🚀 Featured Projects

### 📦 [Demand Forecasting & Inventory Optimization](https://github.com/sasirudh/demand-forecasting-inventory-optimization)
Retail sales forecasting that goes one step further: it turns forecast uncertainty into an inventory decision.
* End-to-end **Python + SQL** pipeline with lag, rolling, calendar and seasonal features
* Benchmarked **SARIMAX, LightGBM and GRU** against a naive baseline
* **RMSE 3,852 vs 5,180** for the naive baseline
* Converted forecast error into **safety-stock policy at a 95% service level**, cutting safety-stock cost by **69%**
* Interactive **Tableau** dashboard for stakeholders

`Python` `SQL` `LightGBM` `GRU` `SARIMAX` `Tableau`

### 🧪 [Experimentation & Causal Inference Framework](https://github.com/sasirudh/experimentation-causal-inference)
A toolkit for answering "did it actually work, and for whom?"
* A/B test analysis with **CUPED** variance reduction to detect smaller effects with the same traffic
* **Uplift modelling** evaluated with **Qini curves** to identify which customers to target (top 30% focus)
* Measures lift in visit rate, with clear reporting of what is causal and what is correlation

`Python` `Causal Inference` `A/B Testing` `Uplift Modelling`

### 🛡️ Hybrid Malware Detection with Fuzzy-Logic Containment
Final-year project and **Indian Patent Application No. 202641025780 A** (published, grant pending).
* Hybrid **LightGBM + GRU + MLP** detection model with a fuzzy-logic containment layer

`Python` `LightGBM` `GRU` `MLP` `Fuzzy Logic`
